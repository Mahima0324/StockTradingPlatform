# 📈 Stock Trading Platform (Java)

A console-based Java application simulating a stock trading environment.  
Built as part of **CodeAlpha Internship – Task 2**.

---

## 🚀 Features
- Market data display with price simulation
- Buy and sell operations
- Portfolio tracking with profit/loss
- Transaction log with timestamps
- Volatility indicator for stocks
- Expandable design (leaderboard, file/database persistence)
